## [未リリース]

### 変更

- 「公開日記」プレビュータブを撤去(`file://`表示時に読み込みが正しく機能せず誤解を招くため)
- 代わりに、現在のノート内の全エントリを一括で公開/非公開にする「すべて公開にする」「すべて非公開にする」ボタンをサイドバーに追加(`bulkSetPublic()`)。一括操作後も個別エントリの🌐ボタンで再度切り替え可能
- 公式公開ドメイン(`ocoe-puipui.github.io`)でアクセスされた場合のみ「閲覧専用デモモード」に切り替わるようにした。新規作成・編集・削除・公開切替・インポート/エクスポート・ノート管理は全て非表示になり、`public_entries.json`の内容のみ読み取り専用で表示される。コードをダウンロードして別環境で実行した場合はフル機能のまま利用できる(アプリコード自体はオープンソースとして維持)
- `LIVE_DEMO_HOSTNAME`の判定コードに、フォーク・ダウンロードして使う人向けの目立つ注意コメントを追加(削除するか自分のドメインに書き換えることを推奨する内容)
- README.mdに「このコードをフォーク・ダウンロードして使う方へ」セクションを追加し、同様の注意喚起をコードを読まない人にも伝わるようにした
- `public_entries.json`をノート単位でグループ化する構造(version 2.0)に変更。ノート名・テーマ・縦書き/横書きの情報を保持し、`exportPublicData()`もこれに合わせて更新
- 閲覧専用デモモードにノートタブ(切替のみ)・Calendar・Recent Activityを復元(専用の`renderDemoTabs`/`renderDemoCalendar`/`renderDemoActivity`等を追加)。編集系UI(新規作成・削除・公開切替・ノート追加/リネーム・インポート/エクスポート)は引き続き非表示
- グリッドレイアウトの`demo-mode`(2カラム)クラスを、公開エントリが0件の場合のみ適用するよう修正(3カラム表示時に右カラムが折り返される表示崩れを解消)
- MITライセンスを追加(`LICENSE`ファイル、`index.html`冒頭のコメント、README.mdへの明記)
- README.mdを全面的に見直し、公開デモについての説明・公開日記機能の説明・フォーク時の注意点・データ構造(`isPublic`/`public_entries.json`)・トラブルシューティングを追加し、利用者向けマニュアルとして整理

### 追加予定

- `public_entries.json` の初回作成・配置、`.gitignore`の例外設定(フェーズ3)
- ブラウザでの実機動作確認(フェーズ4)
- コミット・push・GitHub Pages反映確認(フェーズ5)

### 追加(index.html、コミット前)

- 日記エントリに `isPublic` フィールドを追加(公開/非公開の状態を保持)
- 新規作成・編集フォームに「この日記を公開する」チェックボックスを追加
- サイドバー一覧(INDEX)の各エントリに🌐アイコンの公開マーク切替ボタンを追加
- `exportPublicData()` を実装。公開マーク付きエントリのみを抽出し `public_entries.json` として書き出すボタンをManagementエリアに追加
- アプリ起動時に `public_entries.json` を読み込む処理を追加(ファイル未配置でもエラーにならない)
- タブバーに「🌐 公開日記」タブを追加。公開エントリを読み取り専用で一覧表示する `renderPublicView()` を実装

詳細設計は [DESIGN.md](./DESIGN.md)、進捗チェックリストは [TASKS.md](./TASKS.md) を参照。
