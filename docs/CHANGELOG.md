# Chronicle Diary チェンジログ

最終更新: 2026-08-11

このファイルは主要な機能追加・変更を大まかな単位でまとめたものです。
現時点の仕様の詳細は[DESIGN.md](./DESIGN.md)を、コミット単位の変更履歴はGitのログを参照してください。

## 主な変更

- 個人日記データ(IndexedDB)と公開データ(`public_entries.json`)を分離する設計を導入
- エントリ単位・一括の公開/非公開切り替え機能、公開用データ書き出し機能を追加
- 閲覧専用デモモード(公式公開ドメインでのみ編集系UIを非表示化)を追加
- サイト全体の「お知らせ」機能(HTML入力、公開/非公開、ローカルプレビュー)を追加
- ノート単位のエクスポート/追加インポート機能を追加
- 文字サイズ設定(小/中/大)、INDEX一覧の表示件数選択・ページ送りを追加
- 個別表示/まとめて表示(feed)の表示モード切り替えを追加
- 縦書き/横書きに応じた日英UI切り替えを全体に適用
- お知らせの画像挿入を、日記本文と同様のbase64埋め込み方式(最大3枚、専用ボタン)に変更
- 公開ページ(閲覧専用デモモード)にもINDEXのページ送り・まとめて表示(feed)モードを適用し、規定値(表示件数5・feed)で表示するよう対応
- UIレイアウトを「INDEX系」「SETTING系」「THEME/DIRECTION/FONT SIZE/表示モード」の3グループに整理
- MITライセンスの追加、READMEの利用者向け整備

詳細仕様は[DESIGN.md](./DESIGN.md)、進捗状況は[TASKS.md](./TASKS.md)を参照。
